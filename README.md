# Enciclopédia de Super-Heróis

Este é um projeto escolar de desenvolvimento web focado na construção de uma página simples utilizando **HTML5** e **CSS3**, criado como parte de uma atividade de Front-End. O objetivo principal do desafio foi aplicar tags HTML corretamente e garantir que o código passe ileso pelo validador do W3C (zero erros!).

## 🦸 Heróis e Vilões
A enciclopédia detalha a origem, missão, periculosidade, poderes e feitos dos seguintes personagens:
- **Anakin Skywalker / Darth Vader** (Star Wars)
- **Gamora** (Marvel)
- **Massa Cinzenta** (Ben 10 / Cartoon Network)

## 🚀 Tecnologias Utilizadas
- **HTML5:** Estruturação semântica, listas, tabelas e formatação de texto (negrito, itálico, marca-texto).
- **CSS3:** Estilização externa para cores, fontes e organização visual da tabela.

## ⚙️ Como Executar o Projeto
1. Salve os arquivos `index.html` e `style.css` na mesma pasta no seu computador.
2. Dê um duplo clique no arquivo `index.html`.
3. Ele abrirá automaticamente no navegador padrão do seu sistema.
